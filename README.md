# AI Engineer Roadmap

A community learning path for becoming an AI engineer: **Practice -> Build -> Deploy -> Get Hired**. This roadmap progresses from computer and programming fundamentals through data science, machine learning, generative AI, agents, and production capstone projects.

> Learn in public, work through the topics at your own pace, and share improvements so others can learn too.

## How to use this roadmap

1. Follow the stages in order, or review prerequisites and adapt the sequence to your experience.
2. For each topic, learn the concepts, write code, and complete a small hands-on exercise.
3. Record what you learned, questions you still have, and links to useful references.
4. Build and deploy the Stage 14 capstones to demonstrate practical skills.

The repository is organized so each topic can have its own learning folder and README. For example: `curriculum/stage-02-python-basics/data-structures/README.md`. Topic pages can grow to include explanations, examples, exercises, project work, and further reading.

## Career progression

1. **Practice** - Master core syntax and foundations.
2. **Build** - Develop models, APIs, and agent tools.
3. **Deploy** - Dockerize, deploy to the cloud, and monitor systems.
4. **Get Hired** - Present a production-focused portfolio of AI systems.

**Roadmap strategy:** Master Stages 1-4 for programming foundations, Stages 5-13 for core AI architectures, and Stage 14 for end-to-end production capstones.
